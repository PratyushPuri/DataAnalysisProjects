## 📊 Project Overview

This comprehensive data analysis project explores **AI assistant usage patterns among students** across different educational levels and academic disciplines. The study analyzes 10,000 student sessions to understand how AI tools are integrated into modern educational workflows and their impact on academic productivity.

### 🎯 Key Objectives

- **Analyze usage patterns** across educational levels (High School, Undergraduate, Graduate)
- **Identify discipline-specific trends** in AI assistant adoption
- **Measure effectiveness** through completion rates and satisfaction metrics
- **Understand user behavior** patterns and retention rates
- **Provide actionable insights** for educational technology development

---

## 📁 Dataset Information

| **Attribute** | **Description** |
|---------------|-----------------|
| **Records** | 10,000 student sessions |
| **Time Period** | July 2024 - June 2025 |
| **Educational Levels** | High School, Undergraduate, Graduate |
| **Disciplines** | Biology, Business, Computer Science, Engineering, History, Math, Psychology |
| **Key Metrics** | Session length, prompt count, AI assistance level, satisfaction ratings |

### 📈 Dataset Statistics


| **Total Sessions** | 10,000 |
| **Average Session Length** | 19.85 minutes |
| **Average Prompts per Session** | 5.6 |
| **Average AI Assistance Level** | 3.48/5|
| **Average Satisfaction Rating** | 3.42/5 |
| **Assignment Completion Rate** | 47.68% |
| **User Retention Rate** | 70.64% |

## 🔍 Key Findings

### 📚 Educational Level Distribution
- **Undergraduate**: 59.78% (5,978 sessions) - Dominant user group
- **High School**: 27.07% (2,707 sessions) - Growing adoption
- **Graduate**: 13.15% (1,315 sessions) - Specialized usage
