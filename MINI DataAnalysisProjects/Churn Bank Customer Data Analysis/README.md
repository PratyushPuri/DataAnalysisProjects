## 📊 Project Overview

This comprehensive data analysis project explores customer churn patterns in the banking sector using advanced data visualization and statistical analysis techniques. The project analyzes 10,000 customer records to identify key factors driving customer attrition and provides actionable insights for strategic decision-making.

### 🎯 Key Objectives
- Understand customer demographics and behavioral patterns
- Identify primary churn risk factors and predictors
- Provide data-driven recommendations for customer retention
- Create comprehensive visualizations for stakeholder communication

## 📈 Dataset Information

| Feature | Description | Type |
|---------|-------------|------|
| **CreditScore** | Customer credit score (350-850) | Numerical |
| **Geography** | Customer location (France, Spain, Germany) | Categorical |
| **Gender** | Customer gender (Male, Female) | Categorical |
| **Age** | Customer age (18-92 years) | Numerical |
| **Tenure** | Years with the bank (0-10) | Numerical |
| **Balance** | Account balance (€0-€250,898) | Numerical |
| **NumOfProducts** | Number of banking products (1-4) | Numerical |
| **HasCrCard** | Credit card ownership (0/1) | Binary |
| **IsActiveMember** | Active membership status (0/1) | Binary |
| **EstimatedSalary** | Estimated annual salary | Numerical |
| **Exited** | Customer churn status (TARGET) | Binary |

### 📊 Dataset Statistics
- **Total Records**: 10,000 customers
- **Churn Rate**: 20.37% (2,037 churned customers)
- **Data Quality**: Complete dataset with no missing values
- **Geographic Distribution**: France (50.14%), Spain (~25%), Germany (~25%)

## 🔍 Key Findings

### 🚨 Critical Churn Indicators

| Factor | Impact | Insight |
|--------|---------|---------|
| **Gender** | High | Female customers show 25% higher churn rates |
| **Product Complexity** | Critical | 3-4 products = 83% churn rate |
| **Engagement** | High | Inactive members 2x more likely to churn |
| **Account Balance** | Moderate | High-balance customers at risk |
| **Age** | Moderate | Older customers with low credit scores vulnerable |

### 💡 Strategic Insights


- 🎯 Primary Risk Segment: High-balance, multi-product, inactive female customers
- 📊 Retention Priority: Customer engagement over financial incentives
- 🌍 Geographic Focus: Leverage France success model for Spain/Germany
- ⚡ Quick Wins: Activate dormant customers, simplify product delivery
