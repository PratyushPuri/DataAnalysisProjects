## 📋 Project Overview

This project presents a comprehensive analysis of a synthetic asthma dataset containing 10,000 patient records with 17 variables covering demographic, clinical, and environmental factors related to asthma. The analysis includes exploratory data analysis, beautiful visualizations, and statistical insights into asthma prevalence and management patterns.

## 🎯 Key Features

- **Comprehensive Dataset Analysis**: 10,000 patient records with diverse asthma-related variables
- **Beautiful Visualizations**: 20+ stunning charts and graphs exploring different aspects of asthma
- **Statistical Insights**: Detailed correlation analysis and pattern identification
- **Clinical Relevance**: Analysis of medication adherence, control levels, and emergency visits
- **Environmental Factors**: Investigation of air pollution, occupation, and lifestyle impacts

## 📊 Dataset Information

### Dataset Statistics
- **Total Records**: 10,000 patients
- **Variables**: 17 comprehensive features
- **Asthma Prevalence**: 24.33% (2,433 patients)
- **Age Range**: 1-89 years (mean: 44.9 years)
- **Gender Distribution**: Female 48.14%, Male ~46%, Other ~6%

### Variables Included
- **Demographics**: Age, Gender, BMI
- **Risk Factors**: Smoking Status, Family History, Allergies
- **Environmental**: Air Pollution Level, Occupation Type
- **Clinical**: Peak Expiratory Flow, FeNO Level, Medication Adherence
- **Outcomes**: Asthma Status, Control Level, Emergency Visits

## 📈 Analysis Highlights

### 🔍 Key Findings

- **Age Independence**: Asthma affects all age groups relatively equally
- **Environmental Impact**: Limited correlation between air pollution and respiratory function
- **Control Challenges**: 50.5% of asthma patients are not controlled, 39.8% poorly controlled
- **Allergy Patterns**: Dust allergies most common (35.1%), followed by pollen and pets
- **Medication Adherence**: Average adherence rate of 50% across all patients
